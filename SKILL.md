# Visual Research Library skill
Read `AGENTS.md` and `data/routes.json`. Retrieve matching records from `data/sources.json` or run `python3 tools/search.py "query" --json`. Search original providers for actual assets, verify rights in `docs/rights.md`, and answer with the response contract in `AGENTS.md`. If installed as an agent skill, keep the adjacent data and docs directories available. This skill has no required secrets, external code execution or network access beyond optional provider research.
